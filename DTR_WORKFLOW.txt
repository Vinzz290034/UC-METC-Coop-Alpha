┌─────────────────────────────────────────────────────────────────────────────┐
│                           STAFF WORKFLOW                                     │
└─────────────────────────────────────────────────────────────────────────────┘

1. LOGIN
   ↓
2. NAVIGATE TO DASHBOARD
   ↓
3. SEE STAFFTIMECARD COMPONENT
   ├─ Purple gradient card with clock icon
   ├─ Real-time clock display
   └─ Current date shown
   ↓
4. TIME IN (Before 8 AM = On Time, After 8 AM = Late)
   ├─ Click "Time In" button (green)
   ├─ Records timeIn: HH:MM:SS
   ├─ Records staffId & staffName
   ├─ Sets date: YYYY-MM-DD
   ├─ Sets status: 'on_time' OR 'late'
   └─ Toast notification appears ✓
   ↓
5. WORK THROUGHOUT THE DAY
   ├─ Card shows "Time In: HH:MM:SS"
   └─ Status badge displays (on_time/late)
   ↓
6. TIME OUT (End of shift)
   ├─ Click "Time Out" button (red)
   ├─ Records timeOut: HH:MM:SS
   ├─ Auto-calculates duration: minutes
   └─ Toast notification appears ✓
   ↓
7. CARD SHOWS COMPLETION
   ├─ Time In: HH:MM:SS
   ├─ Time Out: HH:MM:SS
   ├─ Duration: Xh Ym
   └─ Status: 'on_time' or 'late'
   ↓
8. NEXT DAY - REPEAT

│                           ADMIN WORKFLOW                                     │

1. LOGIN (Admin account)
   ↓

   ↓

   ↓
4. APPLY FILTERS
   ├─ Filter by date: Date picker
   ├─ Filter by staff: Dropdown selector
   └─ Export CSV: Download button
   ↓
5. VIEW FILTERED DTR TABLE
   ├─ Staff Name | Date | Time In | Time Out | Duration | Status
   ├─ Color-coded status badges:
   │  ├─ Green: On time
   │  ├─ Yellow: Late
   │  ├─ Red: Absent

   ↓
6. VIEW SUMMARY STATISTICS
   ├─ Total Records for date
   ├─ Attendance Rate %
   ├─ Tardiness Rate %
   ├─ Total Staff count
   ├─ Checked In Today

   ↓
7. EXPORT REPORT
   ├─ Click "Export CSV"
   ├─ Downloads: dtr-records-YYYY-MM-DD.csv
   └─ Includes all filtered records

┌─────────────────────────────────────────────────────────────────────────────┐
│                      DTR RECORD DATA STRUCTURE                              │
└─────────────────────────────────────────────────────────────────────────────┘

DTRRecord {
  id: string                    // Unique identifier: dtr_${timestamp}
  staffId: string               // User's ID from auth
  staffName: string             // First Name + Last Name
  date: string                  // YYYY-MM-DD format (e.g., "2024-01-31")
  timeIn: string                // HH:MM:SS format (e.g., "07:45:30")
  timeOut?: string              // Optional, HH:MM:SS format
  duration?: number             // Optional, in minutes (e.g., 480 = 8 hours)
  status: 'on_time'|'late'|'absent'|'present'  // Attendance status
  createdAt: string             // ISO timestamp when record created
}

┌─────────────────────────────────────────────────────────────────────────────┐
│                      USER ROLE HIERARCHY                                    │
└─────────────────────────────────────────────────────────────────────────────┘

┌─ ADMIN (Full Access)
│  ├─ Can time in/out (own DTR)
│  ├─ Can view ALL staff DTR records
│  ├─ Can filter DTR by date & staff
│  ├─ Can export DTR to CSV
│  └─ Access all system features
│
├─ STAFF (Operational Access)
│  ├─ Can time in/out (own DTR only)
│  ├─ Can view own DTR on dashboard
│  ├─ Cannot view other staff records
│  ├─ Cannot access DTR Management page
│  ├─ Optional specialization:
│  │  ├─ cashier
│  │  ├─ locker_officer
│  │  └─ inventory_officer
│  └─ Access to operational pages
│
├─ MEMBER (Cooperative Member)
│  ├─ Cannot time in/out
│  ├─ Member-specific features only
│  └─ No DTR access
│
└─ USER/STUDENT (General Customer)
   ├─ Cannot time in/out
   ├─ Public features only
   └─ Merchandise ordering only
